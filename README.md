Ignitefeed
Bem-vindo ao Ignitefeed, um projeto de feed social desenvolvido como parte do programa Ignite da Rocketseat. Este projeto é uma aplicação web que permite aos usuários criar, visualizar e interagir com publicações em um feed, com funcionalidades como comentários e curtidas.
🚀 Tecnologias Utilizadas

React: Biblioteca JavaScript para construção de interfaces de usuário.
TypeScript: Superset do JavaScript que adiciona tipagem estática.
Vite: Ferramenta de build e desenvolvimento rápida.
CSS Modules: Estilização modular para componentes React.
Phosphor Icons: Biblioteca de ícones para a interface.
Date-fns: Biblioteca para manipulação e formatação de datas.

📋 Funcionalidades

Visualização do Feed: Exibe uma lista de publicações com informações como autor, data e conteúdo.
Criação de Comentários: Permite aos usuários adicionar comentários às publicações.
Curtir Publicações: Funcionalidade de curtida para interagir com as postagens.
Interface Responsiva: Design adaptável para diferentes tamanhos de tela.

🛠️ Como Executar o Projeto
Siga os passos abaixo para rodar o projeto localmente:
Pré-requisitos

Node.js (versão 16 ou superior)
npm instalado

Passos

Clone o repositório:
git clone https://github.com/Chicuta/Ignitefeed.git
cd Ignitefeed


Instale as dependências:
npm install



Inicie o servidor de desenvolvimento:
npm run dev



Acesse a aplicação:Abra o navegador e vá para http://localhost:5173 (ou a porta indicada no terminal).
